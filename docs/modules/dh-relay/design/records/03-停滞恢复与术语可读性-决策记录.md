## 决策

将“终端已拉起但 Agent 未接单或无可恢复进展”纳入显式恢复合同：身份绑定的 `node_started`/checkpoint 加时限，Monitor 以 Host Observation 产生 Attention，Workflow Engine 生成带 CAS guard 的恢复命令，HostSessionActor 撤销旧身份并在旧 Pair 关闭后创建新 Attempt。Herdr 诊断仅作白名单、脱敏、限长后的恢复证据；Role Relay 仍是非权威、无队列的尽力转发。

## 原因与边界

用户需要能看见“拉起成功”和“真实开始工作”的差别，也需要卡住时可恢复而不让旧 Agent 覆盖新结果。该决策不把 Host/聊天提升为业务真相，也不改变 DevPlan、DHR_30 或现役运行合同。
