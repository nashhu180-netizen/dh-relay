## 边界 (Boundaries)

- **In scope**：树外 Client Bundle 构建配方（含清净重跑与换机重跑）；最小 Relay 面板列表屏 + 详情屏；两屏从 DHR_25 冻结 fixture 重建；装卸与 UI 注册清理证据；`group` 架构约束的跨客户端镜像断言；事实登记（配方全文 / 外部前提 / 止损逐条）。
- **Out of scope**（任务卡非目标，逐条）：不做完整工作台首页 / 项目管理 / 流程编辑器；不做 v1 投影；不接 Relay 运行写权；不修改 DSH 上游源码；**不评判面板视觉质量**（视觉属 P4-X 非阻塞，最小面板阶段判视觉为时过早）。
- **不裁定**：不自行给 DSH 桌面控制面轨贴 `passed / passed-with-constraints / stopped-by-pilot` 三态标签——归 DHR_50 由用户人判收敛。
- **何时必须停下问人**：
  1. **列表屏中途闸**（完成条件 #6）——列表屏一渲染出来就停，交操作路径给用户亲跑并等其明示；这是本卡**计划内的强制暂停点**，不是异常。
  2. §4.4 止损条件命中时，停止扩张、诚实收口为判否事实，把事实摆给用户。
  3. E11 一次性确认本地收口授权包；复核降级请求；P0/P1 三轮不收敛。
  4. 其余按默认——E12/E13 包内机械步骤不重复索权，「待复核 / 待收口」不是停工理由。
