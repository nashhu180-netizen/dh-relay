# DHR_34 · 教训候选

- 候选：身份、额度与普通失败的分类边界必须由受控正反样本冻结；不得用错误文本的宽泛匹配触发账号切换。
- 候选：fallback 不是旧 Attempt 的续写；必须有新的 Attempt / Receipt 与冻结后的身份链。
- 候选：施工期“实现裁决”若填补冻结设计未覆盖的第三种情形，必须先升 findings 并回查需求，不得仅写 progress 就视为合同。
- 候选：复核关闭护栏缺口前，要证明错误实现会使断言变红；“新增用例且为绿”本身不证明判别力。
- 候选：触发自动动作的 detector/白名单条目必须同时有需求出处与咬住该条目的断言；缺任一即不得内置。
