## 抽取标准（筛子）

一条候选要同时满足：

1. **有触发场景**：能写出"下次遇到 X 情形时"，不是泛泛的"要认真"。
2. **可复用**：换一张卡、换一个人也会踩，不是本卡特有的一次性事实。
3. **不是流水账**：`progress.md` 里"第 N 步做了什么"不是教训；"以为 A 其实 B"才是。
4. **不与既有 58 条候选 + 本卡 L-7001~L-7007 重复**。撞上了就**不要另起**，改为指出"应回链候选-N / L-700N"。
