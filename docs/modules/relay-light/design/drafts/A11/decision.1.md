## 2. P1-3：推荐最小 wire format 与原子验收

**分类：方向决策（须用户点选）**：现 O-003/O-004 把事件载体与字段合同列为产品开放项，本报告不能代选。以下随出口 A 一并提交用户；选择后，候选替换、反例补齐属于小决策（编排可代执行）。

### 2.1 语法和字段

保留 JSONL 顶层七字段、note 的字符串类型；仅当 `event=resource_close` 时启用以下完整字符串协议，不解析其他事件的历史自由 note，不增加 status --json 字段：

```text
object_type=pane object_id=pane-7 outcome=ok
object_type=workspace object_id=stage-C1 outcome=failed reason=permission%20denied
object_type=worktree object_id=%2Ftmp%2Frlt24 outcome=ok
```

| 键 | 必填 / 可选 | 解码后合法值 |
|---|---|---|
| object_type | 必填一次 | workspace、pane、worktree，大小写敏感闭集 |
| object_id | 必填一次 | 非空、非纯空白的 UTF-8 文本；记录可辨识的真实资源标识，worktree 使用绝对路径；不在校验时要求资源仍存在（关闭后可能已消失） |
| outcome | 必填一次 | ok、failed，大小写敏感闭集 |
| reason | 条件字段 | failed 必填一次且非空、非纯空白；ok 必须完全不存在该键，reason= 也不允许 |

- token 用**一个 ASCII 空格**分隔，不允许首尾空格、连续空格、裸换行或 Tab；每个 token 恰有一个裸 `=`。键顺序不影响接收，推荐写出顺序按上表。无其它自由尾文。
- 值先编码成 UTF-8，再作百分号编码：裸字符只允许 `[A-Za-z0-9._~-]`，其它字节写 `%HH`，接收大小写十六进制；空格用 `%20`，加号用 `%2B`，`=` 用 `%3D`，百分号用 `%25`。解码只执行一次，`+` 不作为空格。非法 `%` 序列、无效 UTF-8、解码后控制字符均拒绝；标识内普通空格不被 trim 改写。
- 所有键均禁止重复（即使值相同）；未知键、缺键、空值、枚举非法、非字符串 note 均拒绝。不采用最后值覆盖，不把 malformed token 静默忽略。不设置额外可选扩展键。
- 写入者：pane 的 `agent=monitor#<n>, by=monitor`；workspace（阶段空间和编排空间）、worktree 的 `agent=orchestrator#<n>, by=orchestrator`，沿用既有实例名格式。依据 §12“阶段结束编排关整个终端空间”，修正候选把阶段空间一律归 monitor 的提案。实际执行人可为人，账本写入者记录其可观察结果，不把记录权限当成关闭资源授权。
- node 指向相应阶段第一个有效节点；全计划编排空间/worktree 取收口 F 阶段第一个有效节点。须引用存在且非 superseded 的节点；允许在 node_close/stage_close 后记录，不要求 agent_launch，不改变关闭节点/阶段状态。前置的计划合法性、首行 plan_loaded 等通用规则继续成立。同一对象多次关闭尝试逐次记账，不设唯一性限制。
- note 格式、对象标识是事实载体；不得填凭据值。outcome=failed 是关闭尝试失败，不自动等同阶段 failed，也不自动执行删除或重试。

### 2.2 add 与 lint 的拒绝时点

| 入口 | 时点 | 必须行为 |
|---|---|---|
| add | CLI 输入解析后、任何账本字节追加前 | 通用行校验 → 独立事件 writer/node 校验 → 完整 note 语法与字段校验 → reason 条件校验；任一不合法退出 2，账本字节不变。不将 resource_close 送进 agent 状态机 |
| lint | 逐行读取、通用 JSON/七字段/seq 校验后、接受该行或派生状态前 | 对 resource_close 调用与 add 相同的语义校验；任一非法退出 2，指出 seq/字段及原因；只读、不修复、不补默认值。合法 failed 是一条合法事实，不因此让 lint 失败 |

两条入口必须共享同一协议，不允许“add 接收、等 lint 才发现失败原因缺失”。lint 反例应通过临时测试账本直接植入非法行，不能用 add 拒绝的结果代替 lint 覆盖；均使用临时 fixture，不修改 71 行真实账本。
