## 4. H3 — 三 CLI 的 `--config-dir` 与默认目录判定

### 4.1 正式命令签名

§3.1 的三个现有签名分别增加同名可选参数：

```text
relay_log.py add    --plan <dir> --node <n> --event <e> --agent <a> [--note <text>] [--config-dir <dir>]
relay_log.py status --plan <dir> [--json] [--config-dir <dir>]
relay_log.py lint   --plan <dir> [--json] [--config-dir <dir>]
```

三个子命令共用同一个 resolver 与配置加载结果；不得出现某个子命令绕过配置校验或以 `config=None` 跳过 A116/A97。

### 4.2 默认目录闭集

正式 adapter 必须知道自己使用 Claude 侧还是 Codex 侧，并在调用三个 CLI 时显式传入对应默认安装副本：Claude adapter 模板传 `~/.claude/skills/relay-light/`，Codex adapter 模板传 `~/.codex/skills/relay-light/`；relay-log 按 A135 展开成绝对路径。这不是 fixture 路径，而是安装器生成的用户级副本。relay-log 不猜主控或调用进程身份。

解析顺序与结果定义为：

| 情形 | 结果 |
|---|---|
| 显式给 `--config-dir <dir>` | 只使用该目录；优先于所有默认候选 |
| 未显式给，且仅 `~/.claude/skills/relay-light/` 存在 | 使用 Claude 目录 |
| 未显式给，且仅 `~/.codex/skills/relay-light/` 存在 | 使用 Codex 目录 |
| 未显式给，且两侧目录同时存在 | 配置来源有歧义，退出 3，要求显式 `--config-dir` |
| 未显式给，且两侧目录均不存在 | 无配置来源，退出 3，要求先安装或显式 `--config-dir` |

“存在”指候选目录存在；选中后其中任一必需配置缺失、不可读或解析失败，同样 fail closed 退出 3。运行时不合并两目录、不比较两目录内容、不根据调用者是 Claude/Codex 猜身份、不直接回退到仓内 `tools/relay-light/skill/`。

直接手工调用仍适用上表的单侧 fallback；正常 `--all` 安装后两侧并存，正式 adapter 必须显式传路径。`plan_loaded.note` 继续记录实际 `config_dir=` 与 `plan=`。

### 4.3 A99 保号与新增 A135

A99 的既有 2→3 配置驱动 X 规划、核心文件 hash 不变、对外仅三子命令与 plan_loaded 双键均保留；配置措辞只改为“显式目录优先于 §6.2.1 的默认目录”，不把新失败命题塞入 A99。

新增 `HC-RL-A135`：三个子命令均接受 `--config-dir`；直接调用未显式传入时按 §4.2 五情形判定。显式值先按当前用户 home 展开 `~`，再依次做 `abspath`、`normpath`（不解析符号链接）、分隔符统一为 `/` 后判存在，不依赖 shell 展开。`plan_loaded.note` 的 `config_dir=` 记录该规范化绝对路径的百分号编码：使用标准库 `urllib.parse.quote(path, safe="/:~-._")`，因此空格为 `%20`、原始 `%` 为 `%25`，整个值保持单个无空白 token。验证三个子命令 help、Claude-only、Codex-only、双侧、零侧，以及伪造含空格 HOME/USERPROFILE 后显式传 `~/...`；断言账本值可解码回规范化绝对路径。显式优先由 A99 证明，两条共用同一 fixture 时不重复计证。双侧与零侧均断言 rc=3、错误 `HC-RL-A135` 且 ledger 不增行。显式目录不存在也报 A135；选中目录内 `roles.toml` 加载失败报 A131，`dh-mapping.toml` 加载失败报 A92。

新增 `HC-RL-A136`，owner=RLT_07：两份 adapter 中调用 `relay_log.py add/status/lint` 的每个命令模板都显式带本侧默认安装副本的 `--config-dir`；Claude adapter 模板传 `~/.claude/skills/relay-light/`，Codex adapter 模板传 `~/.codex/skills/relay-light/`，由 A135 展开为绝对路径，不出现省略 flag 的正式调用形态。证明方式为枚举每份 adapter 中全部 `relay_log.py add|status|lint` 调用（含 Windows/Linux 变体），每个都含 `--config-dir` 且指向本侧，三个子命令各至少出现一次。

§3.1 三个子命令的退出码 3 同步扩为“relay_plan 缺失/解析失败，配置目录无法判定，或选中配置缺失、不可读、解析失败”。RLT_03 的既有 CLI fixture 改为显式受控 `--config-dir` 属于 fixture 对齐，不改变 A5/A56 命题。
