## 1. 为什么改

2026-09-23 #62 把 SKILL / adapter / AGENTS 里的「监工 monitor」更名为 **stage-lead**，并把 single-task 的只读观察者定名 **watcher**，但明确留下两处未改：①`design/01` 正文仍写「监工」（117 行、140 次）、「monitor」角色；②single-task 的 `phase=monitor` 与 `roles.toml` 的 `[monitor]` 段沿用旧名。结果是用户打开新终端启用 relay-light 时，single-task 仍拉起名为 monitor 的常驻 agent、`roles.toml` 仍有 `[monitor]` 段而无 `[watcher]`（RLT_18 F-011）。用户 2026-09-28 要求「把名字统一」，并点选只统一角色层、账本字段冻结。
